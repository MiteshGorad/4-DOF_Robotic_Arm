# Future Plans

This project is under active development. The following features are planned for future releases.

---

## Version 1.0 ✅

- Manual control using 4 potentiometers
- Smooth servo movement
- Modular firmware architecture
- Configurable GPIO mapping

---

## Version 2.0

- Wi-Fi connectivity
- Responsive web interface
- Real-time remote control
- WebSocket communication
- Manual / Remote mode switching

---

## Version 3.0

- Save robotic arm poses
- Load saved poses
- Motion sequence playback
- Adjustable servo speed
- Home position button

---

## Version 4.0

- Inverse Kinematics (IK)
- End-effector position control
- Coordinate-based movement
- Workspace visualization

---

## Version 5.0

- OTA (Over-the-Air) firmware updates
- Calibration interface
- Servo limit configuration
- Motion profiles
- EEPROM/Preferences storage

---

## Long-Term Goals

- Mobile application control
- Bluetooth Low Energy (BLE) support
- Gamepad/Joystick control
- Voice control
- ROS 2 integration
- Computer vision using OpenCV
- Object tracking
- Pick-and-place automation
- AI-assisted motion planning

---

## Planned Hardware Improvements

- Custom PCB
- Better cable management
- Metal gear servos
- Higher torque actuators
- Servo feedback support
- 3D printed enclosure
- Battery-powered operation

---

## Project Vision

Build an affordable, open-source ESP32-based robotic arm platform for learning embedded systems, robotics, and automation. The project will evolve from manual control to advanced autonomous operation while maintaining a modular and extensible firmware architecture.
